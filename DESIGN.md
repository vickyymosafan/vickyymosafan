# Design Direction: Vicky Mosafan GitHub Ecosystem

## 1. Identity & Visual Language
- **Brand Identity**: M. Vicky Mosafan (Fullstack Developer & Prompt Engineer specializing in AI Augmented Engineering).
- **Core Narrative**: Leveraging AI across the entire software development lifecycle to improve speed, quality, and decision-making while upholding rigorous engineering principles (SOLID, DRY, KISS, modularity).
- **Visual Mood**: Cyber Obsidian & Tokyo Night engineering aesthetic. High contrast, technical depth, crisp typography, and zero generic AI slop.

## 2. Design System Tokens
- **Core Palette**:
  - Base Obsidian: `#0d1117` / `#161b22`
  - Surface Accent: `#1a1b27`
  - Structural Border: `#30363d`
  - Tech Accent Blue: `#70a5fd`
  - Electric Emerald: `#9ece6a`
  - Alert / Highlight: `#ff9e64`
- **Typography**: Clean GitHub system sans-serif hierarchy complemented by developer monospace tokens for code symbols, tech stacks, and metrics.

## 3. Dials
- **ENERGY**: 3 (Bold engineering presence, high-impact visuals, confident technical voice)
- **RHYTHM**: 3 (Asymmetric composition, varied section hierarchy, detailed project briefs over cookie-cutter cards)
- **MOTION**: 2 (Dynamic SVGs, animated streak graphs, live telemetry badges, pacman contribution graph)

## 4. Antislop & Quality Constraints
- **R-02**: Zero em-dashes (`—`) in UI copy.
- **R-03**: Fluid mobile responsiveness without horizontal overflow.
- **R-05 & R-14**: Varied project showcases with real engineering substance, not copy-paste badge walls.
- **R-17 & R-18**: 100% verified GitHub data, real repositories, and truthful project descriptions.
- **R-25**: WCAG AA compliant text contrast across all dark and light themes.
- **R-26**: Every link and button resolves to an active, reachable repository or resource.
